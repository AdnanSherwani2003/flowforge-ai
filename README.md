# FlowForge AI

A local-first AI workflow automation platform built
with n8n, FastAPI, PostgreSQL, Ollama, and Next.js.

## Project Goal

Automate repetitive business operations while retaining
human approval, auditability, and failure recovery.

## Planned Workflows

1. AI-assisted customer support triage
2. Lead intake and deduplication
3. Scheduled daily operations digest

## Technology Stack

- n8n: Workflow orchestration
- FastAPI: Backend and business logic
- PostgreSQL: Persistent application data
- Ollama: Local AI inference
- Next.js: Operational dashboard
- Docker Compose: Local infrastructure
- pytest: Automated testing

## Current Status

Implementation 01: Local infrastructure setup.

This is an engineering portfolio project, not
a production SaaS platform.
